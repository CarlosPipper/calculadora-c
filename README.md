# Calculadora em C

Calculadora simples desenvolvida para praticar lógica de programação e conceitos básicos da linguagem C.

## Funcionalidades

* Adição
* Subtração
* Multiplicação
* Divisão
* Verificação de divisão por zero

## Tecnologias

* C

## Conceitos praticados

* Variáveis
* Entrada e saída de dados
* Operadores matemáticos
* `switch/case`
* Condicionais
* Lógica de programação
